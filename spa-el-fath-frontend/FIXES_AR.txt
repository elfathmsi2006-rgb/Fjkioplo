SPA EL FATH CMMS - Frontend fixes

التعديلات المنفذة:
1) إصلاح فقدان التركيز في حقول النماذج داخل النافذة المنبثقة (Modal). السبب كان إعادة تشغيل useEffect عند كل إعادة عرض بسبب تمرير onClose بدالة جديدة؛ وكان cleanup يعيد التركيز إلى العنصر السابق بعد كل حرف. أصبح مستمع لوحة المفاتيح يثبت طوال عمر النافذة، ويستخدم أحدث دالة إغلاق من خلال ref.
2) إزالة زر «إضافة ورشة» من رأس صفحة الورشات، وإزالة بطاقة «إضافة ورشة» من الشبكة. بقيت وظائف تعديل الورشات وحذفها وعرض التفاصيل كما هي.

التسليم:
- هذا أرشيف المصدر الكامل، ويحتوي على ملفات المشروع وpackage.json وpackage-lock.json.
- تم استبعاد node_modules وdist لتجنب تضمين اعتماديات النظام القديم/ملفات البناء.
- تم التحقق من TypeScript بنجاح باستخدام tsc -b.

التشغيل على Windows:
1. فك ضغط الأرشيف.
2. افتح مجلد spa-el-fath-frontend في VS Code.
3. افتح Terminal داخل المجلد ونفّذ:
   npm.cmd install
   npm.cmd run build
   npm.cmd run dev
4. افتح الرابط المحلي الذي يعرضه Vite.

ملاحظة: لم يتم تغيير الباك إند أو قاعدة البيانات أو ملفات migrations.
